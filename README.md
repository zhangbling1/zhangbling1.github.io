# 张宁 - 个人作品集与后台管理系统

> GitHub Pages 在线展示: [https://zhangbling1.github.io](https://zhangbling1.github.io)

本项目为个人视觉设计与艺术作品集，包含：
- **公开展出端 (`index.html`)**：以“画册”为形式的作品集——纸色底、墨色字、一枚朱红名章；封面、目录、按分类成章、图版编号、深色看图模式、作者页与可打印简历。桌面与手机均可使用。
- **可视化管理后台 (`admin.html`)**：管理全量 1100+ 张素材，支持显示/隐藏切换、标题与标签修改、简历编辑及本地保存与 GitHub 发布。本次只重设计前端，后台保持原样。

### 前端设计说明

首页像一本画册：封面 → 目录 → 各章节 → 封底（联系方式）。每个分类是一章，按 `categories.order` 排列；`visible` 决定是否公开，旧配置中的 `featured` 标记不参与展示。

- **开屏**：第一次打开网站时，一位骑手策马奔跑，马在奔跑中从简到繁：几根线条的骨架（构想）→ 带朱红辅助圆的结构线（结构）→ 墨色剪影（造型）→ 鬃毛、马尾、缰绳和一条红围巾（精修）。作品数据载入后骑手跑出画面、进入封面，全程约 2.5–3 秒；点击、轻触或按任意键可跳过（滚动不会跳过）。每个标签页第一次打开网站时出现；从带锚点的链接进入（如 `…/#about`）或系统开启“减少动态效果”时不出现；想随时再看一遍，打开 `https://zhangbling1.github.io/?intro`。万一脚本出错，最迟 9 秒后也会自动消失。开屏脚本 `js/intro.js` 只在需要时才加载（压缩后约 7KB）。
- **封面**：右侧是缓慢流动的精选作品（桌面三列、平板两列、手机两行），先取 `siteInfo.workOrder` 里的作品，不足时从各章轮流补足；没有预览图的作品、表情贴纸和极端长图不进入（视频以封面帧出现）。鼠标悬停时暂停并在玻璃卡片上显示作品名，点击进入看图模式；卡片上的按钮可以暂停滚动。
- **液态玻璃**：顶部导航、书眉、按钮、看图模式的控件都是半透明的玻璃质感，边缘高光会跟随鼠标；导航下方的“水滴”会滑到当前页。页面滚动后，顶部三个玻璃按钮下方会淡入一层很浅的纸色渐变，避免和下面的图片混在一起。不支持背景模糊的浏览器会自动改用不透明底色。系统开启“减少动态效果”时，所有动效停用。
- **目录**：每章一张卡片，前面是本章第一幅作品，后面露出接下来两幅作品的颜色，像一叠画；鼠标移到哪张卡片，玻璃底板就滑到哪张。手机上变成带缩略图的列表。
- **视频**：图版先显示封面帧和时长，不加载视频；鼠标停留片刻才静音试播，移开即停止下载；点击后在看图模式里带声音播放。视频是 AV1 编码：Chrome、Edge、Firefox 都能播放，Safari 只有较新的设备（iPhone 15 Pro、M3 Mac 及以后）支持，不支持时会显示封面并提示换浏览器。
- **作者页**：工作经历是一组卡片（最近一段占两列），鼠标移上去同样有滑动的玻璃底板；技能是一排标签；“下载 PDF 简历”打印出来仍是单页排版。
- **联系**：封底列出邮箱、微信和电话，各带复制按钮，都来自后台的个人资料。
- **名章**：导航、作者页和封底的红色小方块显示 `siteInfo.brandName` 的第一个字；标语 `heroSubtitle` 在第一个逗号处换行，第二行定时有一道光扫过。
- **章节顺序**：写在 `workOrder` 里的作品排在所在章节最前面，其余按 `sortOrder`。
- **图版编号**：全书统一编号（从 001 起），同一作品只出现在它所属的章节里（封面图即图版 001）。
- **标题**：有正式标题的作品在图版下显示标题；后台默认生成的“CG风格 #12”这类名字只显示编号。
- **排版**：同一行图片等高、左右对齐，一般按原始比例完整展示；在版面里显得过窄的竖图只显示顶部，超宽的全景图居中裁到 2.4:1。真正的长图（宽高比小于 0.5）标注“长图”，在看图模式里可上下滚动看完整。
- **章节预览**：每章默认显示约十幅（整行），点“展开全部”查看本章所有作品。
- **书眉**：滚动到某一章时，顶部导航中间显示当前章节。

所有页面资源和字体均从本站加载。版面优先使用 WebP 预览图（400 / 640 / 1280 三档，按屏幕自动选择），图片到达前先显示该作品的平均色；看图模式先显示预览、再换成高清原文件；预览不存在时回退到原文件。首屏只加载封面上看得见的缩略图，其余在页面加载完成后再取；章节里的图版接近屏幕时才加载。字体是只含拉丁字符的 WOFF2 子集（约 24KB，中文使用系统字体）。新增公开作品后，可运行 `python scripts/build-previews.py` 更新预览和平均色（需要 Pillow），原图不会被改写。视频的封面帧（避开开头和结尾的淡入淡出，挑画面最丰富的一帧）需要额外安装 PyAV：`pip install av`；没装时脚本会保留已有的视频封面，只跳过新视频。

前端为本项目独立实现，没有复制模板代码。Manrope 字体许可位于 `assets/fonts/OFL-Manrope.txt`。

## 快速使用指南

### 1. 启动管理后台进行作品调整（推荐）
在 Windows 电脑上直接双击运行：
```bash
启动管理后台.bat
```
或在终端中运行：
```bash
node scripts/server.js
```
运行后将自动在浏览器中打开后台：`http://localhost:3000/admin.html`。

### 2. 在后台调整作品
- **快速精简素材**：针对 CG 风格的 800+ 张素材，可点击【仅保留前20张】或使用【批量公开 / 批量隐藏】，让作品集更加精练高水准。
- **作品展示**：将作品设为公开即可加入前端画廊；旧版后台的星标目前不影响前端展示。
- **自定义标题与标签**：直接在卡片上输入自定义名称与标签（如 `ComfyUI`, `3D辅助`, `商业项目`）。
- **修改简历与基本信息**：切换至【个人简历与资料】标签页即可直接编辑工作经历与技能。
- **保存配置**：点击右上角【💾 保存修改配置】，配置将自动持久化至本地 `data/portfolio-data.json`。

### 3. 发布更新到 GitHub Pages
调整完成后，只需提交并推送到 GitHub 仓库即可生效：
```bash
git add .
git commit -m "Update portfolio showcase"
git push
```
*(亦可在后台点击【🚀 发布到 GitHub】，填入个人 Personal Access Token 一键提交！)*

## 目录结构说明
```text
zhangbling1.github.io/
├── index.html            # 前台展出首页 (优化后)
├── index.backup.html     # 原版单文件备份
├── admin.html            # 可视化管理控制台
├── 启动管理后台.bat       # 双击启动本地管理服务
├── css/
│   ├── style.css         # 前台“画册”视觉样式
│   └── admin.css         # 后台暗色控制台样式
├── js/
│   ├── app.js            # 画册结构、图版排版、看图模式与作者页
│   ├── intro.js          # 开屏：骑手与奔马（每次浏览只加载一次）
│   ├── particles.js      # 旧版文件；当前前端不加载
│   └── admin.js          # 后台数据管理、批量操作与保存逻辑
├── data/
│   ├── portfolio-data.json  # 当前生效的作品配置与展出清单
│   ├── media-previews.json  # 可选的预览图索引
│   └── all-assets.json      # 全量素材原始索引
├── assets/               # 本地字体、图标与 WebP 预览图
├── images/               # 素材目录 (CG Style, Cartoon, Character等)
└── scripts/
    ├── scan-assets.js    # 素材扫描与数据初始化脚本
    ├── build-previews.py # 生成公开作品的轻量预览图
    └── server.js         # 本地零依赖管理服务 (提供保存API)
```
